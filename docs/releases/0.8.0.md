⚡️**Release Telemetry Viewer** f:0.8.0 b:0.8.0

- Исправлена загрузка заказов после полуночи: видео и телеметрия открываются независимо от даты в имени суточного лог-файла.
- Данные заказа получаем через существующий PostgREST, файлы — по точным ссылкам из БД. При открытии страницы больше не перебираются суточные архивы и предполагаемые имена видео.
- Доступное видео отображается даже при отсутствии или ошибке телеметрии. Добавлены понятные сообщения об ошибках и повторная загрузка.
- Список логов и поиск scanner-архива теперь запускаются по нажатию кнопки.
- Добавлен просмотр записей выбранного лога за время заказа:

GET [https://xapi.xrobotics.io/robot_viewer/api/v1/orders/log-window?machine_id=cb-3-0007&order_id=1794011078.328&log_key=orders%2F2026-11-06_orders.txt.gz](https://xapi.xrobotics.io/robot_viewer/api/v1/orders/log-window?machine_id=cb-3-0007&order_id=1794011078.328&log_key=orders%2F2026-11-06_orders.txt.gz)

*Значение `log_key` выбирается из списка логов машины. Ответ содержит текст в Base64, статус и признак `truncated`, если достигнут лимит чтения. Читается только выбранный файл.*

- Исправлено отображение UTF-8 в логах; содержимое логов не исполняется как HTML. Для файлов свыше лимита просмотра доступно скачивание оригинала.

*Старые заказы без сохранённых ссылок на файлы автоматически не восстанавливаются. Дополнительные точки веса из суточных журналов пока не реконструируются.*
