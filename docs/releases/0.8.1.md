⚡️**Release Telemetry Viewer** f:0.8.1 b:0.8.1

- Возвращены автоматическая загрузка логов заказа и прежние вкладки внизу страницы.
- Видео и телеметрия загружаются независимо от журналов. Медленная загрузка или ошибка логов влияет только на блок Logs.
- Кнопка **Reload logs** повторяет загрузку журналов, не перезагружая заказ и видео.
- Ручной выбор файла сохранён в **Choose another log file**. Выбранный файл открывается в активной вкладке; поздний автоматический ответ не заменяет его содержимое.
- Добавлен отдельный эндпоинт `GET /robot_viewer/api/v1/orders/logs?machine_id=...&order_id=...` для автоматических журналов с ограничениями объёма обработки и явным статусом неполного результата.

*Для автоматического набора сохранена прежняя логика выбора файлов по дате имени. Для других файлов доступен ручной выбор. Видео и основная телеметрия по-прежнему читаются по точным ссылкам из БД.*
