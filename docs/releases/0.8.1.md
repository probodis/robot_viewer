⚡️Release Telemetry Viewer f:0.8.1 b:0.8.1
- Исправлена загрузка видео и телеметрии для заказов после полуночи, если машина работала без перезагрузки и ордер нового дня попал в файл-логи предыдущего дня. Используются точные ссылки на видео-файлы и телеметрии из БД — без зависимости от даты в имени суточного лога.
- Видео отображается даже при отсутствии или ошибке телеметрии. Добавлены понятные сообщения об ошибках и повторная загрузка.
- Логи автоматически загружаются внизу страницы отдельно от видео и графиков. Медленная загрузка или ошибка журналов не блокирует основной экран.
- Кнопка Reload logs обновляет только журналы, без перезагрузки заказа и видео.
- В Choose another log file можно выбрать конкретный файл. Он открывается в активной вкладке; поздний автоматический ответ не перезаписывает выбранное содержимое.
- Поиск scanner-архива запускается кнопкой Find scanner archive.
- Исправлено отображение UTF-8 и безопасный вывод содержимого логов. Для больших файлов доступно скачивание оригинала.

- GET /orders/log-window (https://xapi.xrobotics.io/robot_viewer/api/v1/orders/log-window?machine_id=cb-3-0007&order_id=1794011078.328&log_key=orders%2F2026-11-06_orders.txt.gz) — записи выбранного файла за время заказа.
